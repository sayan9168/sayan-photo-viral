## How to Enable GitHub Pages

1. Go to the repository: https://github.com/sayan9168/sayan-photo-viral
2. Click **Settings** → **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Branch: `main` / folder: `/ (root)`
5. Click **Save**
6. Wait 1–2 minutes → Open: https://sayan9168.github.io/sayan-photo-viral/
